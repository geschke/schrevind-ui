
# schrevind-ui

Web-based admin ui for **Schrevind**.

This is a minimal Vue.js frontend for managing comments and sites in a Schrevind backend installation. It provides basic moderation features and is designed to stay lightweight and focused.

## Status

**Work in progress**

The ui is currently under active development.
APIs, structure and features may change at any time.

Do not use in production environments yet.
