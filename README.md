
# schrevind-ui

Web-based admin ui for **Schrevind**.

This is a minimal Vue.js frontend for managing depots, securities, withholding tax defaults and users in a Schrevind backend installation. It is designed to stay lightweight, transparent and focused on the application's narrow use case.

## Status

**Work in progress**

The ui is currently under active development.
APIs, structure and features may change at any time.

Do not use in production environments yet.
